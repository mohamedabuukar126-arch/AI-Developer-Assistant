# AI Developer Assistant

An AI-powered developer assistant built with Python and Flask.

I built this project to create a tool that can help with coding, files, conversations, and other developer tasks. It includes AI chat, conversation history, file uploads, memory, document handling, and voice input.

## Status

**Alpha**

This project is not actively maintained at the moment, so some features may contain bugs or may not work as expected.

## Features

* AI developer chat
* Conversation history
* File uploads
* Document handling
* AI memory
* Voice input
* Settings
* 2,000-character message limit
* Rate limiting
* SQLite database
* Flask backend

## Built With

* Python
* Flask
* SQLite
* HTML / CSS / JavaScript
* OpenRouter API

## Setup

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
cd AI-Developer-Assistant
```

### 2. Install the requirements

```bash
pip install -r requirements.txt
```

### 3. Create a `.env` file

Add your OpenRouter API key:

```env
OPENROUTER_API_KEY=your_api_key
```

### 4. Run the application

```bash
python app.py
```

Then open the local address shown in the terminal.
